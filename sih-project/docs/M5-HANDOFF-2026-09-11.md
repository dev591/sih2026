the N-CMAPSS benchmark notebook. Nothing was lost — the run had already
finished and autosaved before the crash. Likely cause: OOM, since
`sih-project/ml/benchmarks/data/` is ~32GB (full-resolution N-CMAPSS,
gitignored, never pushed to GitHub — private-repo LFS quota is 1GB, nowhere
near enough) and the old laptop only had 8GB RAM. Rather than risk a repeat,
the user copied the whole `sih2026` folder — including the 32GB dataset —
